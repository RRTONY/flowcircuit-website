# Team Dimensions Profile (TDP) Status & Open Source Alternatives

## Commercial Status of Team Dimensions Profile
*   **Status:** Conflicting reports. One source (KnowledgeWorkx, 2013) explicitly states "The Team Dimensions Profile is no longer sold by Wiley." However, other vendors (Internal Change, DISC Value Profiles) still list it as a product, often as a "non-DISC product" or complement.
*   **Publisher:** Originally Inscape Publishing, acquired by Wiley.
*   **Current State:** It appears to be a "legacy" product. It is not the flagship; "The Five Behaviors of a Cohesive Team" (based on Lencioni) is the current focus for Wiley.
*   **Implication:** While it may still be purchasable through legacy distributors, it is effectively "abandonware" in terms of active development. This creates a massive opening for a modern, digital-first replacement.

## The "Human OS 2.0" Opportunity
Since TDP is fading, "Human OS 2.0" can claim the mantle of the **"Modern Standard for Innovation Teams."**

## Open Source / Scientific Alternatives for Upgrade
To build a legally distinct and scientifically superior model, we should integrate:

1.  **The Big Five (OCEAN) - "Innate Traits":**
    *   *Why:* The gold standard in academic psychology. Highly replicable.
    *   *Application:* Map "Openness to Experience" to **Creator** and "Conscientiousness" to **Executor**. This grounds the Z-Process in hard science.

2.  **Google's Project Aristotle - "Team Norms":**
    *   *Why:* Proved that *who* is on the team matters less than *how* they interact (Psychological Safety).
    *   *Application:* The "Facilitator" role isn't just a person; it's a set of *norms* (Psychological Safety protocols).

3.  **Organizational Network Analysis (ONA) - "Communication Flow":**
    *   *Why:* Visualizes how information actually moves vs. the org chart.
    *   *Application:* The "Who To Go To" matrix is essentially a simplified ONA. We can use this terminology to sound more data-driven.

## Strategic Pivot

**"The first framework to combine the Big Five (Innate Personality) with Agile/Design Thinking (Process) using Network Analysis (Communication)."**

This triangulation makes it unassailable by legacy IP and far more attractive to modern enterprises.
